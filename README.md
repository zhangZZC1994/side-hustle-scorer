## 为什么做这个

市面上的"副业教程"都在教你**怎么干**，没人先帮你判断**该不该干**。

大多数人副业失败不是因为不够努力，而是一开始就选了一个结构上不成立的方向——
投入三个月才发现它停手即停收，本质是出卖时间，不是积累资产。

这个工具只做一件事：**在投入时间之前，先把结构问题暴露出来。**

---

## 核心判断：你做的是不是真复利？

判断标准只有一句话：

> **我停手一个月，它还在赚钱吗？**

在，就是资产；不在，就是时薪。

工具里的「复利潜力」维度权重是 2.0×，是八个维度里最高的——因为这一项决定了其他七项有没有意义。

## 八个维度与权重

| 维度 | 权重 | 说明 |
|------|------|------|
| 复利潜力 | **2.0×** | 成果能否沉淀为资产，越做越轻松 |
| 技能匹配度 | 1.5× | 你现有的能力能不能直接上手 |
| 市场需求 | 1.5× | 真的有人愿意为此付钱吗 |
| 启动成本低 | 1.0× | 需要投入的资金，越低越好 |
| 时间弹性 | 1.0× | 能否碎片化推进 |
| 竞争强度 | 1.0× | 5 = 几乎没人做，1 = 红海 |
| 变现速度 | 1.0× | 多久能收到第一笔钱 |
| 可持续性 | 1.0× | 三年后这事儿还在不在 |
